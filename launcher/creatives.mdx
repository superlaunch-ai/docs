---
title: "Create and version creatives"
description: "Save immutable content versions, select exact versions, and review their media."
---

A creative contains your ad copy and media. Superlaunch saves content edits as separate versions so you can select and launch specific content. The tools call the parent creative a **creative family**.

## Create a creative

1. Open **Launcher → Creatives → Library**.
2. Select **New creative**.
3. Enter a name and the organizing fields you need.
4. Choose the supported format and language.
5. Add the message, headline, destination, and required identity fields.
6. Choose saved media for the format and any supported placement variants.
7. Save the creative and inspect its version.

The content schema includes single images, single videos, carousels, collections, flexible ads, existing posts, and catalogs. Multilingual content and placement media use saved variant and slot assignments. Schema support does not guarantee that an account, objective, or placement can launch a format. Use account capabilities and preview to check the exact combination.

## Select a saved version

Saved draft content is eligible for launch checks. You do not need a separate approval step. Inspect the copy, media, language, and destination before submitting a launch.

Content edits create a new immutable version. Use `launcher_creatives_get` to page through saved version summaries and `launcher_creative_versions_get` to read exact content. Pin `creative_id` and `creative_version_id` pairs in `selection.creative_versions`. You can select distinct versions of one creative in the same launch.

## Revoke or archive

Revoke a version when you need to prevent its selection. Archive the family when you want to remove it from active library use.

Earlier launches retain their recorded content inputs. Revocation does not rewrite provider objects created by earlier launches.

## Check usage

Use the creative's usage view or `launcher_creatives_usage` to find launches that used it. Read `launcher_creatives_get` or `launcher_creative_versions_get` when you need exact version details.
