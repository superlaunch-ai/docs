title: "Organize collections"

Collections help you reuse a selection of creatives.

## Choose a collection kind

A **fixed collection** contains the creative families you select. Use it for a reviewed set of concepts or an explicit campaign package.

A **smart collection** uses filters such as name, concept, approved language, approved format, tags, source, or import date. Conditions combine with AND; values within a condition act as alternatives. Add exclusions if a matching creative should stay out.

## Create a collection

1. Open **Launcher → Collections**.
2. Create a collection and enter its name.
3. Choose fixed or smart selection.
4. Add members or filters.
5. Review the selected or matching creatives.
6. Select **Save collection**.

Smart-filter previews show current matches. Launch preparation still checks which exact versions are approved.

## Resolve a launch selection

Use the resolve-selection control or `launcher_collections_resolve` to obtain a selection for a launch. Check exclusions and rejected items before submission.

A saved launch preserves its resolved inputs. Later library edits do not retroactively replace the creative versions used by that launch.

## Edit or archive

Read the current collection before editing or archiving it through MCP. Use its current lock version where required. For scheduled selection behavior, see [Recurring launches](/launcher/schedules).
