Add images and videos under **Launcher → Creatives → Import media**, then use them in a [creative](/launcher/creatives).

## Upload a file

1. Select **Upload files** and choose an image or video.
2. Select **Upload selected file**.
3. Keep the page open until the upload finishes.
4. Check the media item's status and preview before using it.

The upload control shows the file types and size limits. If a thumbnail fails, check the media status and retry the thumbnail before uploading the file again.

## Import from Google Drive

1. Select **Import from Google Drive**.
2. Connect your Google account if prompted.
3. Select the files you want to make available to Superlaunch.
4. Review the selection and select **Import selected files**.
5. Check the results for files that need another attempt.

Superlaunch can read files you select through Google Picker. Selecting a folder does not give access to all its files or start an import. Select each new batch of files before refreshing the folder browser.

## Upload through an AI client

Clients that support the Superlaunch upload picker can accept up to ten files per batch, with a default combined limit of 64 MiB. Ask your assistant to upload your images or videos to the workspace library.

If your client cannot show the picker, use the browser steps above. The assistant can find saved files with `launcher_media_list` and read their details with `launcher_media_get`.

Developers can also use the [signed upload workflow](/mcp/workflows) and [media tool reference](/mcp/reference/actions).
