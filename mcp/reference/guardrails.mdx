## guardrails_capabilities

Read Guardrails settings schemas, selection bounds, and current grants.

**Access:** `mcp:read`. Workspace and target permissions also apply.

**Arguments:** none.

<Accordion title="Full input schema">

```json
  "properties": {},
  "type": "object"
}
```
