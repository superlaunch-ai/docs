Call `insights_capabilities` before querying. Choose the reporting period, entity level, metrics, conversion event, and attribution window. Follow query cursors before reporting complete results.

## insights_query

Read one page of reporting data. Call `insights_capabilities` to check supported combinations.

Pages default to 25 rows, with a maximum of 100. Follow `next_cursor` with the same filters to read more. Use sorting and `min_spend` to narrow results, or `entity_ids` to inspect specific objects.

For structured metrics such as `actions` and `action_values`, supply both `action_types` and `attribution_windows`. For example, use `action_types: ["omni_purchase"]` and `attribution_windows: ["7d_click"]` for purchases attributed within seven days of a click. Choose these values to match the report you need.

Daily account, campaign, and ad-set totals can aggregate compatible metrics from ad rows. Reach and frequency use the requested reporting level.

**Access:** `mcp:read`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `ad_account_ids` | array of uuid | Required |  minItems: `1`. maxItems: `20`. |
| `date_from` | string | Required | First reporting date in `YYYY-MM-DD` format. |
| `date_to` | string | Required | Last reporting date in `YYYY-MM-DD` format. |
| `metrics` | array of strings | Required | minItems: `1`. maxItems: `20`. Allowed values are in the full input schema. |
| `entity_level` | account, campaign, adset, ad | `"ad"` | Reporting level: account, campaign, ad set, or ad. |
| `entity_ids` | array of string or null | `null` |  |
| `report_spec` | base_daily, demographic_daily, country_daily | `"base_daily"` | Report format from `insights_capabilities`. |
| `grain` | daily, period | `"daily"` | Time grouping from `insights_capabilities`. |
| `action_types` | array of string or null | `null` | Conversion events to include in structured metrics. |
| `attribution_windows` | array of value, 1d_click, 7d_click, 1d_view or null | `null` | Attribution windows to include in structured metrics. |
| `min_spend` | number or null | `null` | Minimum spend in account-currency major units. |
| `sort_by` | entity_id, date, spend, impressions, clicks, ctr, purchases, roas | `"entity_id"` |  |
| `sort_direction` | asc, desc | `"asc"` |  |
| `sort_action_type` | string | `"omni_purchase"` |  |
| `sort_attribution` | value, 1d_click, 7d_click, 1d_view | `"value"` |  |
| `limit` | integer | `25` |  minimum: `1`. maximum: `100`. |
| `cursor` | string or null | `null` |  |

<span id="insights-rank" />

## insights_rank

Rank performance over a date range. Choose one reporting level, then use `global` for a combined ranking across accounts or `per_account` for separate rankings.

Conversion metrics require an explicit event and attribution window. Set minimum spend or conversion filters to exclude low-data results. `highest` and `lowest` refer to numeric values; lower CPA can be better. This tool returns compact rankings without pagination.

**Access:** `mcp:read`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `ad_account_ids` | array of uuid | Required |  minItems: `1`. maxItems: `20`. |
| `date_from` | string | Required | First reporting date in `YYYY-MM-DD` format. |
| `date_to` | string | Required | Last reporting date in `YYYY-MM-DD` format. |
| `entity_level` | campaign, adset, ad | Required | Reporting level: account, campaign, ad set, or ad. |
| `rank_by` | spend, impressions, clicks, ctr, cpc, cpm, conversions, conversion_value, cpa, roas | Required | Metric to rank by. |
| `action_type` | string | `"omni_purchase"` |  minLength: `1`. maxLength: `200`. |
| `attribution_window` | value, 1d_click, 7d_click, 1d_view | `"value"` |  |
| `direction` | highest, lowest, both | `"both"` | Return highest values, lowest values, or both. |
| `rank_scope` | global, per_account | `"global"` | Combined ranking (`global`) or one ranking per account (`per_account`). |
| `statuses` | array of string or null | `null` |  |
| `min_spend` | number or null | `null` | Minimum spend in account-currency major units. |
| `min_impressions` | integer or null | `null` |  |
| `min_clicks` | integer or null | `null` |  |
| `min_conversions` | number or string or null | `null` |  |
| `limit` | integer | `5` |  minimum: `1`. maximum: `20`. |
