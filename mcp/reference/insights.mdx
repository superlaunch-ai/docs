## insights_query

Query one bounded insights page, then follow next_cursor when needed. Call `insights_capabilities` first for valid combinations. The default page contains 25 rows and the MCP maximum is 100 rows to keep tool results within agent context limits. Prefer the default instead of requesting the maximum unless a larger page is necessary. Daily account, campaign, and adset queries automatically roll up aggregation-safe metrics from ad rows; reach and frequency remain exact native metrics at the requested level. Filter structured metrics with `action_types` and `attribution_windows` instead of returning every raw Meta action tuple. Both filters are REQUIRED for actions, action_values, and other structured metrics. For purchase analysis, for example, supply action_types=["omni_purchase"], attribution_windows=["value"]. Choose the action and attribution window that match the question; they are not inferred. Use sorting and `min_spend` before paginating for top-N analysis; use `entity_ids` for targeted follow-up queries.

**Access:** `mcp:read`. Workspace and target permissions also apply.

| --- | --- | --- |
| `ad_account_ids` | array | Required |

| `entity_level` | account, campaign, adset, ad | `"ad"` |

| `report_spec` | base_daily, demographic_daily, country_daily | `"base_daily"` |
| `grain` | daily, period | `"daily"` |
| `action_types` | array or null | `null` |
| `attribution_windows` | array or null | `null` |
| `min_spend` | number or null | `null` |
| `sort_by` | entity_id, date, spend, impressions, clicks, ctr, purchases, roas | `"entity_id"` |
| `sort_direction` | asc, desc | `"asc"` |
| `sort_action_type` | string | `"omni_purchase"` |
| `sort_attribution` | value, 1d_click, 7d_click, 1d_view | `"value"` |

<span id="insights-rank" />

## insights_rank

Rank compact period performance without returning raw insight pages. Use one entity level per call and choose an explicit conversion action and attribution window for conversion metrics. `highest` and `lowest` are numeric extremes, not automatic business judgments. `global` returns one ranking across the requested accounts; `per_account` returns one bounded ranking for each account. Add minimum evidence filters for meaningful results. The result never includes raw structured Meta metric arrays or a pagination cursor.

**Access:** `mcp:read`. Workspace and target permissions also apply.

| Parameter | Type | Required / default |
| --- | --- | --- |
| `ad_account_ids` | array | Required |
| `date_from` | string | Required |
| `date_to` | string | Required |
| `entity_level` | campaign, adset, ad | Required |
| `rank_by` | spend, impressions, clicks, ctr, cpc, cpm, conversions, conversion_value, cpa, roas | Required |
| `action_type` | string | `"omni_purchase"` |
| `attribution_window` | value, 1d_click, 7d_click, 1d_view | `"value"` |
| `direction` | highest, lowest, both | `"both"` |
| `rank_scope` | global, per_account | `"global"` |
| `statuses` | array or null | `null` |
| `min_spend` | number or null | `null` |
| `min_impressions` | integer or null | `null` |
| `min_clicks` | integer or null | `null` |
| `min_conversions` | number or string or null | `null` |
| `limit` | integer | `5` |
