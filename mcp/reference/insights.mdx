Call `insights_capabilities` before querying. Choose the reporting period, entity level, metrics, conversion event, and attribution window. Follow query cursors before reporting complete results.

The parameter tables show the top-level arguments and common nested objects. Expand the input schema for nested formats, constraints, and allowed values.

## insights_query

Query one insights page, then follow next_cursor when needed.  Call ``insights_capabilities`` first for valid combinations. The default page contains 25 rows and the MCP maximum is 100 rows to keep tool results within agent context limits. Prefer the default instead of requesting the maximum unless a larger page is necessary. Daily account, campaign, and adset queries automatically roll up aggregation-safe metrics from ad rows; reach and frequency remain exact native metrics at the requested level. Filter structured metrics with ``action_types`` and ``attribution_windows`` instead of returning every raw Meta action tuple. Both filters are REQUIRED for actions, action_values, and other structured metrics. For purchase analysis, for example, supply action_types=["omni_purchase"], attribution_windows=["value"]. Choose the action and attribution window that match the question; they are not inferred. Use sorting and ``min_spend`` before paginating for top-N analysis; use ``entity_ids`` for targeted follow-up queries.

**Access:** `mcp:read`. Object and function permissions also apply.

## insights_rank

Rank compact period performance without returning raw insight pages.  Use one entity level per call and choose an explicit conversion action and attribution window for conversion metrics. ``highest`` and ``lowest`` are numeric extremes, not automatic business judgments. ``global`` returns one ranking across the requested accounts; ``per_account`` returns one ranking for each account. Add minimum evidence filters for meaningful results. The result never includes raw structured Meta metric arrays or a pagination cursor.

**Access:** `mcp:read`. Object and function permissions also apply.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `ad_account_ids` | array of uuid | Required |  minItems: `1`. maxItems: `20`. |
| `date_from` | string | Required | See input schema. |
| `date_to` | string | Required | See input schema. |
| `entity_level` | campaign, adset, ad | Required | See input schema. |
| `rank_by` | spend, impressions, clicks, ctr, cpc, cpm, conversions, conversion_value, cpa, roas | Required | See input schema. |
| `action_type` | string | `"omni_purchase"` |  minLength: `1`. maxLength: `200`. |
| `attribution_window` | value, 1d_click, 7d_click, 1d_view | `"value"` | See input schema. |
| `direction` | highest, lowest, both | `"both"` | See input schema. |
| `rank_scope` | global, per_account | `"global"` | See input schema. |
| `statuses` | array of string or null | `null` | See input schema. |
| `min_spend` | number or null | `null` | See input schema. |
| `min_impressions` | integer or null | `null` | See input schema. |
| `min_clicks` | integer or null | `null` | See input schema. |
