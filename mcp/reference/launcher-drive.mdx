Authorize Google Drive and select files or folders in Superlaunch first. These tools expose selected items under `drive.file`. An empty result does not mean the folder is empty. Folder selection does not grant access to all children or start automatic importing.

The tables list arguments and common nested fields. Expand **Full input schema** for all fields and allowed values. Workspace and account permissions apply to every tool.

## launcher_drive_folders_list

List saved workspace folders. Connect Google Drive in Superlaunch first.

**Access:** `mcp:read`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `connection_id` | uuid | Required | Google Drive connection UUID. |

## launcher_drive_folders_save

Save a folder selected in Superlaunch's Google Picker. Select the media files too: folder selection alone does not grant access to its children or start an import.

**Access:** `mcp:read` and `mcp:write`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `connection_id` | uuid | Required | Google Drive connection UUID. |
| `folder_id` | string | Required |  pattern: `^[A-Za-z0-9_-]{1,200}$`. |
| `protected_manifest_ref` | uuid or null | `null` | Protected selection reference returned by the Drive picker. |

**Retries:** check the current state before repeating the operation.

<Accordion title="Full input schema">

```json
{
  "additionalProperties": false,
  "properties": {
    "connection_id": {
      "format": "uuid",
      "type": "string"
    },
    "folder_id": {
      "pattern": "^[A-Za-z0-9_-]{1,200}$",
      "type": "string"
    },
    "protected_manifest_ref": {
      "anyOf": [
        {
          "format": "uuid",
          "type": "string"
        },
        {
          "type": "null"
        }
      ],
      "default": null,
      "type": [
        "string",
        "null"
      ]
    }
  },
  "required": [
    "connection_id",
    "folder_id"
  ],
  "type": "object"
}
```

</Accordion>

## launcher_drive_folder_files_list

List up to 100 files and folders that you selected through Google Picker. An empty result can mean that you have not selected files in that folder.

Follow `next_page_token` for more selected items. Protected folder references expire after one hour. This tool lists files; use the browser to import them.

**Access:** `mcp:read`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `connection_id` | uuid | Required | Google Drive connection UUID. |
| `folder_id` | string | Required |  pattern: `^[A-Za-z0-9_-]{1,200}$`. |
| `parent_folder_id` | string or null | `null` | Google Drive folder to browse. |
| `parent_manifest_ref` | uuid or null | `null` | Protected reference for the parent folder. |
| `search` | string | `""` |  maxLength: `200`. |
| `media_type` | all, image, video | `"all"` |  |
| `page_token` | string or null | `null` | `next_page_token` from the preceding Drive result. |
