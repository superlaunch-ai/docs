title: "Launcher schedules and limits"

Schedules use saved template and selection settings. Read the current version before editing. Existing runs keep their original settings. Account limits cap Launcher campaign counts and configured budgets; they do not cap all spending in Meta.

The tables list arguments and common nested fields. Expand **Full input schema** for all fields and allowed values. Workspace and account permissions apply to every tool.

<span id="launcher-schedules-create" />

## launcher_schedules_create

Create a recurring launch with saved template and selection settings. Overlapping runs are skipped.

**Access:** `mcp:read` and `mcp:write`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `data` | object | Required | Schedule name, launch inputs, timing, and limits. |

### data fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `schema_version` | 1 | `1` | Input format version. |
| `name` | string | Required |  minLength: `1`. maxLength: `200`. |
| `request` | object | Required | Launch inputs, including the account, content selection, template, and timing. |
| `cron_expression` | string | Required |  minLength: `9`. maxLength: `100`. |
| `timezone` | string | Required |  |
| `batch_limit` | integer | Required |  minimum: `1`. maximum: `1000`. |
| `batch_budget_limit_minor` | integer | Required |  exclusiveMinimum: `0`. |
| `enabled` | boolean | `true` |  |

**Retries:** after a timeout, read the current state before submitting again to avoid duplicate changes.

## launcher_schedules_change_status

Pause or resume future scheduled runs. Runs already created keep their saved settings.

**Access:** `mcp:read` and `mcp:write`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `ad_account_id` | uuid | Required | Superlaunch account UUID from `ad_accounts_list`. |
| `schedule_id` | uuid | Required | Schedule UUID from `launcher_schedules_list`. |
| `enabled` | boolean | Required |  |
| `expected_version` | integer | Required |  minimum: `1`. |

**Retries:** read the current state after a timeout. If the change has already applied, do not submit it again with an old version.

<Accordion title="Full input schema">

```json
{

  "properties": {
    "ad_account_id": {
      "format": "uuid",

      "format": "uuid",
      "type": "string"
    },
    "enabled": {
      "type": "boolean"
    },
    "expected_version": {
      "minimum": 1,
      "type": "integer"
    }
  },
  "required": [
    "ad_account_id",
    "schedule_id",
    "enabled",
    "expected_version"
  ],
  "type": "object"
}
```

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
