Discover exact provider assets and targets before preparing a launch. Preview reserves nothing. Submission uses one stable request key and returns work to track. Read operation results before retrying; corrected replacement inputs require a new request key.

The tables list arguments and common nested fields. Expand **Full input schema** for all fields and allowed values. Workspace and account permissions apply to every tool.

## launcher_assets_list

Find Meta Pages, Instagram accounts, pixels, audiences, and other assets by name.

Pages, apps, pixels, and audiences use the selected ad account. Forms, Instagram accounts, and catalogs require a Page ID in `parent_id`. Product sets require a catalog ID in `parent_id` plus a `page_id`.

Pages and Instagram accounts use imported data; check `sync_status` and `synced_at`. Other asset types use live Meta reads. Follow `next_cursor` for more results. Launch validation checks whether the selected assets can be used.

**Access:** `mcp:read`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `ad_account_id` | uuid | Required | Superlaunch account UUID from `ad_accounts_list`. |
| `kind` | pages, instagram_accounts, pixels, applications, lead_forms, product_catalogs, product_sets, custom_audiences | Required | Supported discovery edges, never arbitrary Graph paths. |
| `parent_id` | string or null | `null` |  |
| `page_id` | string or null | `null` |  |
| `limit` | integer | `50` |  minimum: `1`. maximum: `100`. |
