## launcher_assets_list

Find named Meta assets without copying IDs from another product. Pages, apps, pixels and audiences use the selected account. Forms, Instagram and catalogs require parent_id=Page ID. Product sets require parent_id=catalog ID plus page_id. Pages and Instagram accounts come from the synced ClickHouse catalog; inspect sync_status and synced_at for freshness. Other assets use live Meta discovery. Follow next_cursor; discovery does not guarantee launch eligibility.

**Access:** `mcp:read`. Workspace and target permissions also apply.

| Parameter | Type | Required / default |
| --- | --- | --- |
| `ad_account_id` | uuid | Required |

| `parent_id` | string or null | `null` |
| `page_id` | string or null | `null` |
| `limit` | integer | `50` |

<span id="launcher-launches-submit" />

## launcher_launches_submit

Submit exact inputs durably using one stable request key; effects run asynchronously. Pin selection.creative_versions pairs for saved-version choice; manual_groups.creative_version_ids assign those exact versions independently. Another saved version requires no retest reason; reusing the same confirmed version needs retest_reason. Reserved or uncertain usage cannot be retested. Corrected failed items require replacement metadata, pinned saved versions, an exact existing target and a new request key.

**Access:** `mcp:read` and `mcp:write`. Workspace and target permissions also apply.

| Parameter | Type | Required / default |
| --- | --- | --- |
| `request` | object | Required |
