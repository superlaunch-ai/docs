---
description: "Manage media, creative versions, approvals, collections, and templates."
---

Library objects belong to the authorized workspace. Save content edits as new versions, then approve the exact version. Media IDs, creative family IDs, creative version IDs, and template version IDs refer to different objects.

The tables list arguments and common nested fields. Expand **Full input schema** for all fields and allowed values. Workspace and account permissions apply to every tool.

## launcher_template_versions_create

Save new template settings as a separate version. Existing schedules keep their selected version.

**Access:** `mcp:read` and `mcp:write`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `template_id` | uuid | Required | Template UUID from `launcher_templates_list`. |
| `data` | object | Required | Named reusable exact template version input. |
| `expected_version` | integer | Required |  minimum: `1`. |

### data fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `schema_version` | 1 | `1` | Input format version. |
| `name` | string | Required |  minLength: `1`. maxLength: `200`. |
| `config` | object | Required | Saved campaign, ad-set, budget, delivery, and naming settings. |
