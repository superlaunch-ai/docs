Read `rules_schema` for the current rule vocabulary. Read the current rule version before an update. `rules_update` replaces the definition. `rules_run` defaults to dry-run mode.

The parameter tables show the top-level arguments and common nested objects. Expand the input schema for nested formats, constraints, and allowed values.

<span id="rules-schema" />

## rules_schema

Return the rule-builder vocabulary and write requirements.

**Access:** `mcp:read`. Object and function permissions also apply.

**Arguments:** none.

<Accordion title="Full input schema">

```json
{
  "additionalProperties": false,
  "properties": {},
  "type": "object"
}
```

</Accordion>

## rules_list

**Access:** `mcp:read`. Object and function permissions also apply.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `limit` | integer | `25` | See input schema. |

```json

  "additionalProperties": false,
  "properties": {
    "limit": {
      "default": 25,
      "type": "integer"
    }
  },
  "type": "object"
}
```

</Accordion>

<span id="rules-create" />

## rules_create

Create one rule after target and functional authorization.

**Access:** `mcp:read` plus `mcp:write`. Object and function permissions also apply.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `payload` | object | Required | Complete canonical rule create request. |

### payload fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `request_id` | uuid | Required | See input schema. |
| `name` | string | Required |  minLength: `1`. maxLength: `300`. |
| `provider` | string | `"meta"` |  minLength: `1`. maxLength: `64`. |
| `status` | draft, active, paused | `"draft"` | See input schema. |
| `ad_account_ids` | array of uuid | Required |  minItems: `1`. maxItems: `20`. |
| `level` | campaign, adset, ad | `"ad"` | Advertising hierarchy levels that rules may target. |
| `target_filter` | object | Required | Nested target predicates. |
| `tasks` | array of object | Required |  minItems: `1`. maxItems: `20`. |
| `schedule` | object | Required | Validated cron schedule and IANA timezone. |
| `execution_limit` | object or null | `null` | See input schema. |
| `dry_run` | boolean | `true` | See input schema. |
| `metadata` | object | Optional | See input schema. |

**Retries:** the tool does not advertise idempotent replay. Read the current state before repeating a write.

## rules_update

Replace one rule; first read it and preserve every unchanged field.

**Access:** `mcp:read` plus `mcp:write`. Object and function permissions also apply.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `rule_id` | uuid | Required | See input schema. |
| `payload` | object | Required | See input schema. |

### payload fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `request_id` | uuid | Required | See input schema. |
| `name` | string | Required |  minLength: `1`. maxLength: `300`. |
| `provider` | string | `"meta"` |  minLength: `1`. maxLength: `64`. |
| `status` | draft, active, paused | `"draft"` | See input schema. |
| `ad_account_ids` | array of uuid | Required |  minItems: `1`. maxItems: `20`. |
| `level` | campaign, adset, ad | `"ad"` | Advertising hierarchy levels that rules may target. |
| `target_filter` | object | Required | Nested target predicates. |
| `tasks` | array of object | Required |  minItems: `1`. maxItems: `20`. |
| `schedule` | object | Required | Validated cron schedule and IANA timezone. |
| `execution_limit` | object or null | `null` | See input schema. |
| `dry_run` | boolean | `true` | See input schema. |
| `metadata` | object | Optional | See input schema. |
| `expected_version` | integer | Required |  minimum: `1`. |
