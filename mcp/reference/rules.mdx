## rules_schema

Return rule vocabulary; call rules_capabilities for account event values.

**Access:** `mcp:read`. Workspace and target permissions also apply.

**Arguments:** none.

<Accordion title="Full input schema">

```json

  "additionalProperties": false,
  "properties": {},
  "type": "object"
}
```
