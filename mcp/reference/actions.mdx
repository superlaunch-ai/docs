---
title: "Direct Meta actions"
description: "Upload media, create Meta objects, duplicate setups, and change delivery status."
---

Call `actions_capabilities` to check whether live Meta changes are enabled. Creation, duplication, and status requests default to `dry_run: true`. Campaigns, ad sets, and ads created through these tools start paused. Direct budget amounts use integer account-currency minor units.

The tables list arguments and common nested fields. Expand **Full input schema** for all fields and allowed values. Workspace and account permissions apply to every tool.

<span id="actions-capabilities" />

## actions_capabilities

**Access:** `mcp:read`.

**Arguments:** none.

## media_uploads_create

Open a media picker or prepare a signed upload to the workspace library. The picker accepts up to ten files, with a default total limit of 64 MiB. To get a signed upload URL for one file, supply its metadata.

A successful upload saves the file in the library. Use `media_asset_id` with Launcher tools or `media_id` with `creatives_create`. Uploading a file does not create a Meta creative.

**Access:** `mcp:read` and `mcp:write`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `payload` | object | Required | Request ID and optional file metadata for a signed upload. |

### payload fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `request_id` | uuid | Required | UUID for this operation; use a new UUID for changed inputs. |
| `ad_account_id` | uuid or null | `null` | Superlaunch account UUID from `ad_accounts_list`. |
| `filename` | string or null | `null` | Original file name, including its extension. |
| `mime_type` | image/jpeg, image/png, image/webp, video/mp4, video/quicktime or null | `null` | File content type, such as `image/jpeg`. |
| `byte_size` | integer or null | `null` | File size in bytes. |
| `checksum_sha256` | string or null | `null` | SHA-256 checksum of the file bytes. |

**Retries:** reuse the same `request_id` with unchanged inputs for the same operation.
