Resolve Superlaunch account and brand IDs before reading or changing objects. Asset IDs identify provider objects; account IDs identify Superlaunch records.

The tables list arguments and common nested fields. Expand **Full input schema** for all fields and allowed values. Workspace and account permissions apply to every tool.

## brands_create

Create a brand profile and grant its creator write access. Optional fields include website, industry, description, markets, and languages. Assign ad accounts separately.

**Access:** `mcp:read` and `mcp:write`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `payload` | object | Required | Create a workspace brand; reuse request_id only for identical retries. |

### payload fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `request_id` | uuid | Required | UUID for this operation; use a new UUID for changed inputs. |
| `name` | string | Required |  minLength: `1`. maxLength: `200`. pattern: `\S`. |
| `website` | string or null | `null` |  |
| `industry` | string or null | `null` |  |
| `description` | string or null | `null` |  |
| `markets` | array of string | Optional |  maxItems: `50`. |
| `languages` | array of string | Optional |  maxItems: `50`. |

**Retries:** reuse the same `request_id` with unchanged inputs for the same operation.

## brands_update

Update selected profile or brand-kit fields. Omitted fields keep their values; empty lists clear markets or languages. A kit change saves a new version. Supply `kit.positioning` when creating the first kit.

**Access:** `mcp:read` and `mcp:write`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `brand_id` | uuid | Required | Brand UUID from `brands_list`. |
| `payload` | object | Required | Partially update a brand; reuse request_id only for identical retries. |

### payload fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `request_id` | uuid | Required | UUID for this operation; use a new UUID for changed inputs. |
| `name` | string or null | `null` |  |

| `markets` | array of string or null | `null` |  |
| `languages` | array of string or null | `null` |  |

## assets_list

List a page of campaigns, ad sets, ads, or creatives for an account.

**Access:** `mcp:read`.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `ad_account_id` | uuid | Required | Superlaunch account UUID from `ad_accounts_list`. |
| `level` | campaign, adset, ad, creative | Required | Asset level: campaign, ad set, ad, or creative. |
| `limit` | integer | `25` |  minimum: `1`. maximum: `200`. |
| `cursor` | string or null | `null` |  |

<Accordion title="Full input schema">

```json
{
  "$defs": {
    "AssetCursor": {
      "anyOf": [
        {
          "pattern": "^[0-9]+$",
          "type": "string"
        },
        {
          "type": "null"
        }
      ]
    },
    "AssetLevel": {
      "enum": [
        "campaign",
        "adset",
        "ad",
        "creative"
      ],
      "type": "string"
    },
    "AssetLimit": {
      "maximum": 200,
      "minimum": 1,
      "type": "integer"
    }
  },
  "additionalProperties": false,
  "properties": {
    "ad_account_id": {
      "format": "uuid",
      "type": "string"
    },
    "level": {
      "$ref": "#/$defs/AssetLevel"
    },
    "limit": {
      "$ref": "#/$defs/AssetLimit",
      "default": 25
    },
    "cursor": {
      "$ref": "#/$defs/AssetCursor",
      "default": null,
      "type": [
        "string",
        "null"
      ]
    }
  },
  "required": [
    "ad_account_id",
    "level"
  ],
  "type": "object"
}
```

</Accordion>
