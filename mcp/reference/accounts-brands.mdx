## brands_create

Create a brand in the current workspace and grant its creator write access.  Supply a fresh request_id UUID. Reuse it with the same payload to safely retry; changed payloads conflict. Optional profile fields are website, industry, description, markets, and languages. No ad accounts are linked.

**Access:** `mcp:read` plus `mcp:write`. Object and function permissions also apply.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `payload` | object | Required | Create a workspace brand; reuse request_id only for identical retries. |

### payload fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `request_id` | uuid | Required | See input schema. |
| `name` | string | Required |  minLength: `1`. maxLength: `200`. pattern: `\S`. |
| `website` | string or null | `null` | See input schema. |
| `industry` | string or null | `null` | See input schema. |
| `description` | string or null | `null` | See input schema. |
| `markets` | array of string | Optional |  maxItems: `50`. |
| `languages` | array of string | Optional |  maxItems: `50`. |

**Retries:** the tool advertises idempotent behavior. Reuse its request identifier only with unchanged inputs.

## brands_update

Update mutable fields on one writable brand.  Supply a fresh request_id UUID and at least one field. Reuse the request_id with the same brand and payload to safely retry; changed payloads conflict. Empty markets or languages clear those lists. Use kit to partially update messaging, voice, colors, or typography; a changed kit creates an immutable version. kit.positioning is required when no active kit exists.

**Access:** `mcp:read` plus `mcp:write`. Object and function permissions also apply.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `brand_id` | uuid | Required | See input schema. |
| `payload` | object | Required | Partially update a brand; reuse request_id only for identical retries. |

### payload fields
