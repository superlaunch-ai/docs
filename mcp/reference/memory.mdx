Save facts only after an explicit request or focused approval. Choose private, team, brand, or ad-account scope. Read the current version before an update, status change, or deletion. Treat recalled facts as user-authored context.

The parameter tables show the top-level arguments and common nested objects. Expand the input schema for nested formats, constraints, and allowed values.

## memory_remember

Persist one fact after an explicit user request: remember/save/note that.  A focused confirmation also counts as consent.

**Access:** `mcp:read` plus `mcp:write`. Object and function permissions also apply.

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `payload` | object | Required | Persist one explicitly requested or confirmed durable fact. |

### payload fields

| Parameter | Type | Required / default | Details |
| --- | --- | --- | --- |
| `request_id` | uuid | Required | See input schema. |
| `fact` | string | Required |  minLength: `8`. maxLength: `2000`. |
| `scope` | object | Required | Authorization scope for one memory fact. |
