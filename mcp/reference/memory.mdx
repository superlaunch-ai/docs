## memory_recall

Recall bounded semantically relevant user-authored context. Prefer top-level query and optional scope (kind and target_id). Scope restricts recall to that scope only. Object and JSON-string scopes work. Alternatively supply the legacy payload; never mix the two formats. Without scope, use brand_ids/ad_account_ids and include_private/include_team.

**Access:** `mcp:read`. Workspace and target permissions also apply.

| Parameter | Type | Required / default |
| --- | --- | --- |
| `payload` | object or null | `null` |
| `query` | string or null | `null` |
| `scope` | object or string or null | `null` |
| `brand_ids` | array or null | `null` |
| `ad_account_ids` | array or null | `null` |
| `include_private` | boolean or null | `null` |
| `include_team` | boolean or null | `null` |
