## custom_metrics_import_prepare

Validate up to 100 complete daily values. Preview does not publish values. Use a CSV grant for larger imports.

**Access:** `mcp:read` and `mcp:write`. Workspace and target permissions also apply.

| Parameter | Type | Required / default |
| --- | --- | --- |
| `ad_account_id` | uuid | Required |
| `idempotency_key` | string | Required |
| `rows` | array | Required |

Keep the argument nesting shown in the schema. Expand it for nested fields, allowed values, and limits.

<Accordion title="Full input schema">

```json
{
  "additionalProperties": false,
  "properties": {
    "ad_account_id": {
      "format": "uuid",
      "type": "string"
    },
    "idempotency_key": {
      "type": "string"
    },
    "rows": {
      "items": {
        "additionalProperties": false,
        "description": "One complete daily value; no caller storage timestamps.",
        "properties": {
          "metric_id": {
            "format": "uuid",
            "type": "string"
          },
          "entity_level": {
            "enum": [
              "account",
              "campaign",
              "adset",
              "ad"
            ],
            "type": "string"
          },
          "entity_id": {
            "maxLength": 300,
            "minLength": 1,
            "type": "string"
          },
          "date": {
            "format": "date",
            "type": "string"
          },
          "value": {
            "pattern": "^-?(0|[1-9][0-9]{0,19})(\\.[0-9]{1,8})?$",
            "type": "string"
          }
        },
        "required": [
          "metric_id",
          "entity_level",
          "entity_id",
          "date",
          "value"
        ],
        "type": "object"
      },
      "maxItems": 100,
      "minItems": 1,
      "type": "array"
    }
  },
  "required": [
    "ad_account_id",
    "idempotency_key",
    "rows"
  ],
  "type": "object"
}
```
