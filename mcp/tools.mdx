Find a tool by name or task. This reference lists all 97 Superlaunch MCP tools. The tools available in your client depend on approved access, client settings, and enabled features.

## Calling tools

Use an MCP client with [OAuth authorization](/mcp/authentication). The JSON examples are argument objects for named tools. They are not standalone HTTP bodies. A parameter named `payload`, `request`, `data`, `family`, or `content` must keep that nesting.

Read tools require `mcp:read`. Write tools also require `mcp:write` and the relevant workspace, account, and functional permissions.

[Argument examples](/mcp/examples) show valid input shapes for common tasks. See [IDs and retries](/concepts/ids-and-versions) before issuing writes.
