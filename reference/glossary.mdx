---
title: "Glossary"
description: "Definitions for the terms used in Superlaunch and its MCP tools."
---

| Term | Meaning |
| --- | --- |
| Workspace | Team context for members, connections, billing, and shared content |
| Provider connection | Authorization that lets Superlaunch access an advertising platform |
| MCP connection | Authorization that lets an AI client use Superlaunch on your behalf |
| Ad account | Provider account with its own currency, time zone, and assets |
| Campaign | Meta object that defines a campaign objective and related settings |
| Ad set | Meta object with targeting, optimization, delivery, and ads |
| Ad | Delivery object that uses a creative |
| Brand kit | Versioned positioning, voice, colors, fonts, and proof points |
| Memory | A saved fact available to later conversations within its chosen scope |
| Creative family | Workspace library object containing saved content versions |
| Creative version | Exact content, format, language, and media saved at one point |
| Approval | Permission to select an exact creative version for supported launches |
| Collection | Fixed selection or smart filter over library creatives |
| Template version | Saved settings for campaign, ad-set, budget, and naming behavior |
| Launch | Submitted batch of work with saved settings and operation results |
| Schedule | Configuration for recurring launch or rule execution |
| Rule | Targeted conditions and actions with scheduling settings |
| Dry run | A check of inputs or rule decisions without making live changes in Meta |
| Activity | Permission-filtered record of a tool call, action, or rule operation |
| Idempotent retry | Replay of the same intended operation with the same key and inputs |
| Minor units | Smallest currency denomination; an amount of `1000` minor units means USD \$10.00 |
| Attribution window | Reporting interval used to count an event after an ad interaction |
| Cursor | Token or offset for the next page of a filtered result |
